# Smart Data Dashboard Builder - Руководство пользователя

В этом руководстве описан основной рабочий процесс: от импорта данных до публикации и экспорта.

## 1. Быстрый старт

1. Откройте приложение.
2. Нажмите **Загрузить** на верхней панели и выберите файл `.csv` или `.json`.
3. Добавьте виджеты из левой панели (**KPI**, **Bar**, **Line**, **Pie**, **Table**, **3D**).
4. Выберите виджет на канвасе и настройте поля справа (вкладка **Widget**).
5. Примените глобальные фильтры во вкладке **Filters**.
6. Сохраните текущее состояние через **Рабочее пространство -> Сохранить дашборд**.

## 2. Режимы рабочего пространства

- **Build** - полный редактор (библиотека виджетов + канвас + панель настроек).
- **Analyze** - фокус на анализе (канвас + панель настроек).
- **Present** - чистый режим для демонстрации.
- **Discover** - отдельный режим исследования данных с запросом/временем и статистикой полей.

Переключайте режимы кнопками в контекстной панели.

## 3. Требования к импорту данных

Поддерживаемые форматы:

- CSV с заголовком и минимум одной строкой данных
- JSON-массив объектов

Рекомендации:

- Сохраняйте стабильные имена колонок между сессиями (для сохраненных виджетов).
- Для числовых графиков убедитесь, что в колонках значений действительно числа.
- Фильтрация по времени работает лучше, если поле содержит корректные date/time строки или timestamp.

## 4. Сборка дашборда

### Добавление и размещение виджетов

- Используйте левую панель для добавления виджетов.
- Перетаскивайте и изменяйте размер карточек на канвасе.
- Дублируйте/удаляйте карточки через действия в карточке виджета.

### Настройка данных виджета

Используйте правую панель -> вкладка **Widget**:

- **KPI**: агрегация, поле значения, опциональное сравнение.
- **Bar/Pie/3D Bar**: категория + значение.
- **Line**: X + Y.
- **3D Scatter**: X + Y + Z, опционально категория для детализации.
- **3D Surface**: X + Y + Z для реконструкции поверхности.
- **Table**: колонки и лимит строк.

### Стилизация виджетов

Используйте правую панель -> вкладка **Style**:

- прозрачность фона
- радиус скругления
- толщина границы
- глубина тени
- палитра графика
- цвет фона 2D-виджетов

Стили применяются только к выбранному виджету.

## 5. Режим Discover

Режим Discover оптимизирован для исследования сырых данных.

### Запрос и фильтр времени

- Используйте поле запроса в контекстной панели (стиль KQL-lite):
  - `country:USA`
  - `sales>100`
  - `country:USA AND sales>=1000`
- Выберите поле времени и диапазон (`last15m`, `last24h`, `last7d`, `last30d`, `all`).
- Используйте **Редактор запроса** для сложных запросов в Monaco Editor.

### Возможности таблицы Discover

- Сортировка и пагинация результатов.
- Управление видимыми полями.
- Закрепление полей для приоритета.
- Настройка пропорции между таблицей и панелью статистики.
- Сохранение и восстановление пресетов поиска (Saved Searches).

### Панель статистики поля

Для выбранного поля Discover показывает:

- количество строк и уникальных значений
- топ значений
- числовую сводку (`min`, `max`, `avg`, `p50`, `p90`, `p95`)
- корзины гистограммы

## 6. Фильтры

Глобальные фильтры влияют и на виджеты дашборда, и на Discover.

Доступные типы фильтров:

- числовой диапазон
- значения категорий
- текстовые операторы (`contains`, `startsWith`, `equals`, `isNull`)

Используйте сохраненные наборы фильтров и закрепленные поля для повторяемых сценариев анализа.

## 7. Сохранение, загрузка, закладки

Через верхнее меню:

- **Рабочее пространство -> Сохранить дашборд**
- **Рабочее пространство -> Загрузить дашборд**
- **Закладки -> Сохранить текущий вид**
- загрузка/удаление закладок

Сохраняемое состояние включает:

- виджеты и layout
- глобальные фильтры
- состояние discover (query/time/layout)
- режим рабочего пространства

## 8. Экспорт и публикация

Используйте меню **Export**:

- CSV с отфильтрованными данными
- JSON-конфигурация дашборда
- PNG-снимок
- PDF через печать браузера

Используйте **Опубликовать снимок**, чтобы создать локальный снимок для совместной работы.

## 9. Горячие клавиши

- `Ctrl+S` - сохранить дашборд
- `Ctrl+L` - загрузить дашборд
- `Ctrl+Z` - отмена
- `Ctrl+Shift+Z` / `Ctrl+Y` - повтор

## 10. Переключение языка

Используйте селектор **EN/RU** на верхней панели, чтобы переключать язык интерфейса между английским и русским.

## 11. Решение проблем

- **Нет данных на графике**: проверьте выбранные поля и типы числовых колонок.
- **Сохраненный дашборд некорректен**: сбросьте рабочее пространство и сохраните заново с текущей схемой.
- **Медленный рендер на больших данных**: уменьшите объем строк и число активных 3D-виджетов.
- **Запрос возвращает 0 строк**: проверяйте части запроса по отдельности и имена полей.
