### Основной функционал

### 1. Дашборд и Мониторинг
*   **Асинхронная загрузка:** Имитация API-запроса с задержкой и отображением Skeleton-лоадеров.
*   **Сетка питомцев:** Адаптивная CSS Grid верстка (через MUI Box).
*   **Фильтрация:** Возможность отфильтровать питомцев по виду (CyberCat, RoboDog, MechaBird и т.д.) с мемоизацией списка (`useMemo`).

### 2. Карточка Питомца (Pet Card)
*   **Сложное состояние:** Управление логикой через `useReducer` (Feed, Cheer, Level Up, Reset).
*   **Жизненный цикл:** Автоматическое уменьшение энергии и смена настроения через кастомный хук `usePetLifecycle`.
*   **Механика "Смерти":** При энергии 0% питомец переходит в статус `OFFLINE`. Таймеры останавливаются, управление блокируется, аватар обесцвечивается.

### 3. Системный Лог (Event Log)
*   **Глобальный контекст:** Все события (кормление, смена настроения, ошибки) записываются в глобальный `EventContext`.
*   **Боковая панель:** Лог отображается в `MUI Drawer` справа.
*   **Цветовая индикация:** Разные типы событий (Info, Success, Alert) подсвечиваются разными цветами.

## Улучшения 

### Визуальные эффекты 
1.  **Киберпанк-кнопки (Styled Components):** Используется свойство `clip-path` для создания срезанных углов кнопок.
2.  **Динамическая шкала здоровья (Inline Styles):** Цвет и ширина полоски энергии меняются через инлайн-стили для максимальной производительности обновлений.
3.  **Анимация "Тряски" (SCSS + useRef):** Прямая манипуляция DOM-элементом. Когда энергия падает ниже 30%, аватар начинает "трястись" и подсвечиваться красным.
4.  **Смешанная стилизация:** SCSS Modules для структуры карточки, MUI для лейаута, Styled Components для интерактивных элементов.
5.  **Использование localStorage:** логи о состояния питомцев не сбрасываются при перезагрузке страницы благодаря localStorage.
6.  **Happiness bar:** помимо energy bar был добавлен happiness bar для отражения уровня счастья. Животное не может быть до конца довольным в случае, если уровень счастья низок.

##

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Dolce-Vitah/NIS-REACT-DENISENKO.git
    cd cyber-zoo
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер разработки:**
    ```bash
    npm run dev
    ```

4.  **Откройте в браузере:**
    Перейдите по ссылке, указанной в терминале (`http://localhost:5173`).
