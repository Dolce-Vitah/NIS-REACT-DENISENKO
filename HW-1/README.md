### Доработки


Что добавлено для улучшения дизайна:

- для отображения иконок (плитка/список/избранные) использовалась библиотека react-icons;
- было добавлено автозаполнение при поиске фильма;
- звёздочка для добавления в избранные (только в режиме "плитка") появляется только тогда, когда на наводите на постер. Это сделано для освобождения от нагромождений;
- постеры появляются плавно;

Что добавлено из непройденного материала:

- чтобы фильмы не удалялись из избранных при каждом обновлении страницы, добавлен localStorage. Также в localStorage добавляются фильтры и разметка, чтобы при обновлении страницы всё оставалось на местах.
